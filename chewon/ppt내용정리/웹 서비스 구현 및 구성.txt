[4-1. 웹 서비스 구현 및 구성]
슬라이드 제목: 웹 서비스 구현 및 구성
핵심 설명: 구급 수요 분석·예측 결과와 실시간 응급실 병상 정보를 하나의 웹 서비스로 통합하여 제공
주요 기능
- 메인 화면에서 분석·예측과 실시간 병상 관제 서비스로 이동
- 분석·예측 결과를 웹 대시보드로 시각화
- 공공데이터 API를 연계하여 실시간 응급실 병상 정보 제공
- 공통 메뉴를 통해 메인 / 분석·예측 / 병상 관제 화면 간 이동
이미지에 표시할 번호
① 분석·예측: 구급 수요 분석 및 AI 예측 결과 확인
② 병상 관제: 서울시 응급실 가용병상 현황 확인
하단 문구
Flask · HTML/CSS · JavaScript · Chart.js · 공공데이터 API

[4-2. 구급 수요 분석·예측 및 상세 분석]
슬라이드 제목: 구급 수요 분석·예측 및 상세 분석
핵심 설명: 과거 구급 이송 실적과 AI 예측 결과를 시각화하여 서울 전체 및 자치구별 미래 구급 수요를 확인할 수 있도록 구현
주요 기능
- 1~6개월 예측 기간 선택
- 서울 전체 및 자치구별 구급 수요 조회
- 과거 이송 실적과 미래 예측 결과 비교
- 자치구별 예상 수요 순위 확인
- 생활인구·이송 관계·사고 유형·연령대 등 상세 분석 제공
- 자치구별 및 AI 모델의 예측 정확도 확인
이미지에 표시할 번호
- 사진 ① (분석·예측 화면 상단)
  ① 기간 선택: 1~6개월 예측 범위 선택
  ② 핵심 지표: 예상 이송량·피크 시점·증가 지역·정확도
  ③ 수요 예측: 과거 실적과 미래 예측 추세 비교
  ④ 지역 비교: 자치구별 예상 수요 순위
- 사진 ② (상세 분석 화면)
  ⑤ 상세 분석: 생활인구 예측 및 구급 이송과의 관계 분석
하단 문구
분석 데이터: 2017.01 ~ 2025.12  |  예측 기간: 2026.01 ~ 2026.06

[4-3. 실시간 응급실 병상 관제]
슬라이드 제목: 실시간 응급실 병상 관제
핵심 설명: 공공데이터 API와 연계하여 서울시 응급실 가용병상 정보를 조회하고, 지역별 병상 상황을 한 화면에서 확인할 수 있도록 구현
주요 기능
- 서울 25개 자치구 병상 현황 통합 조회
- 서울시 총 가용병상 자동 집계
- 자치구별 위험 · 주의 · 원활 상태 구분
- 자치구 및 병원명 검색
- 권역별 / 위험도별 필터링
- 병원별 가용병상 정보 확인
이미지에 표시할 번호
① 실시간 현황: 총 가용병상 및 위험·주의 지역 집계
② 검색: 자치구 또는 병원명으로 검색
③ 필터: 권역 및 위험도별 조회
④ 병상 정보: 자치구·병원별 가용병상 확인
위험도 범례
🔴 위험: 자치구 가용병상 5석 이하
🟠 주의: 자치구 가용병상 10석 이하
🟢 원활: 그 외
주석 문구
※ 강북구·마포구는 실시간 가용병상 API 미제공으로 등록 응급실 병상 정보 및 인접 자치구 정보를 별도 제공
